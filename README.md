# 💰 Expense Tracker

A simple, beginner-friendly Python application that helps users record, manage, and track their daily expenses. This project demonstrates fundamental Python programming concepts and file handling using JSON.

## 📌 Features

- ➕ Add new expenses
- 📋 View all recorded expenses
- 💵 Calculate total expenses
- 💾 Save expense records in a JSON file
- 🔄 Load saved expenses when the program runs again
- 🖥️ Simple, menu-driven console interface

## 🛠️ Technologies Used

- **Python** — Core programming language
- **JSON** — Persistent storage for expense records

## 🚀 How to Run

### 1. Install Python

Install Python if it is not already installed on your computer.

### 2. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual GitHub repository URL.

### 3. Open the Project Folder

```bash
cd YOUR_PROJECT_FOLDER
```

### 4. Run the Application

```bash
py main.py
```

If your main Python file has a different name, replace `main.py` with that filename.
